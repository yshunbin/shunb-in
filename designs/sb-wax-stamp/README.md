## Client review notes

- Prefer circular dies (standard wax seal). Typical finished diameters: **22–30 mm**.
- Concepts 01–06 show wax-impression mockups for mood and style.
- Concept 07 is closer to a **stamp-die line drawing** for fabrication.
- After a style is chosen, the designer should refine letter spacing, stroke weight, and border for the final engraving size.
- Confirm letter order (**S** left / **B** right vs stacked) and whether a border ring is required.

## Suggested next steps

1. Pick 1–2 preferred directions with the customer.
2. Refine to a clean vector (SVG / AI) at final die size.
3. Export black/white reverse artwork for the stamp maker.
4. Optional: test print at actual scale before cutting the metal die.
